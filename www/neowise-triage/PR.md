# Обработка сбоев AI при разборе заявок

Пустой ввод и битый JSON теперь возвращают 400 invalid_input. Ошибки AI, некорректные темы, пустые черновики и превышение 300 мс возвращают 200 manual_review с topic: null и draft: null.

Результат AI проверяется на сервере в handleTriage: JSON, тема из delivery/pricing/other, непустая строка draft. Ответ формируется явно из разрешенных полей. Имитатор не изменен. Promise.race ограничивает ожидание, AbortController отменяет работу имитатора, таймер очищается.

Страница показывает понятные названия тем и черновик через textContent. При сбое предлагает ручной разбор. Предыдущий черновик очищается сразу при отправке, даже при пустом вводе. Ошибки сети и JSON также ведут к ручному разбору. Счетчик запросов не позволяет старому ответу заменить свежий, отмена уменьшает лишнюю работу. Ожидание HTTP на странице ограничено тремя секундами.

Использован AI: ChatGPT/Codex для подготовки решения и тестов. Автоматически проверены контракт настоящего HTTP-обработчика без открытия сетевого порта, все пять сценариев имитатора, очистка и восстановление черновика, пустой ввод и обратный порядок ответов. Проверки страницы исполняют ее настоящий обработчик в Node.js VM с имитацией DOM и fetch. Ручная проверка в браузере не выполнялась.

Запуск: `node server.mjs`. Тесты: `node --test triage.test.mjs`. Node.js 20+, без зависимостей и ключей.

Польза менеджеру: меньше времени на подготовку ответа без риска использовать устаревший черновик; измерять медианное время от открытия заявки до одобренного ответа и долю черновиков без правок.
