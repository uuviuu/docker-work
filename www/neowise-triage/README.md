# Тестовое Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки, получает тему и черновик ответа. Он читает результат и сам решает, что отправить клиенту.

## Запуск

Нужен Node.js 20 или новее. Зависимостей и ключей нет.

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через переменную PORT.

## Требования

- POST /api/triage принимает JSON с непустой строкой text. Некорректный ввод возвращает HTTP 400 и {"status":"invalid_input"}.
- Успех: HTTP 200 и {"status":"ready","topic":"…","draft":"…"}. Темы: delivery, pricing, other. Черновик непустой.
- Таймаут 300 мс, ошибка или некорректный ответ AI: HTTP 200 и {"status":"manual_review","topic":null,"draft":null}.
- При сбое показать ручной разбор и очистить предыдущий черновик. Добавить исполнимый тест.
- Имитатор не изменять. Метки: [timeout], [error], [bad-json], [bad-topic], [empty-draft].
- Начальный код сохранить первым коммитом, решение в отдельной ветке. В PR описать проверку AI, сбои, использование AI и самостоятельные проверки, пользу менеджеру и метрику.
